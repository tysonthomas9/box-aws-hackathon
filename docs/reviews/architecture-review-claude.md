Verdict: ship with changes — keep a narrow phase 1 experiment; the present demo and acceptance claims are not ready to implement.

Top risks:

1. **Blocker — hidden procedure test is not answerable as designed.** Scenario 5 withholds the E57 family yet expects an unseen proprietary error-to-voltage relationship; a general troubleshooting habit cannot establish that fact. Put the diagnostic facts in the question, withhold only the procedure pattern, and accept abstention when facts are absent. This is a logical defect in the brief, not an AWS limitation.
2. **Blocker — Ask cannot reliably finish synchronously.** The chosen HTTP API has a hard [30-second integration limit](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-quotas.html); imported-model requests may take [up to five minutes or return ModelNotReadyException](https://docs.aws.amazon.com/bedrock/latest/userguide/invoke-imported-model.html). Return 202 plus a job ID, run modes independently, persist partial results, and poll; warming alone is insufficient.
3. **Blocker — “clean account” and “couple of hours” are unsupported promises.** SageMaker GPU training quotas can [default to zero](https://docs.aws.amazon.com/general/latest/gr/sagemaker.html), and [Spot may wait or stop without falling back to on-demand](https://docs.aws.amazon.com/sagemaker/latest/dg/model-managed-spot-training.html). Make approved quotas, Claude access and a successful paired import/invoke prerequisite; pin a tested training image and dependencies, cap waits, and explicitly allow on-demand training.
4. **High — demo scope contradicts phase 1.** Scenarios 1–3 and 6 rely on TensorFold, but phase 1 promises their runbook before phase 2; the 2–3 minute update is not established for LoRA→merge→import→eval. Ship Sources/Review plus one pre-trained Qwen comparison and a real asynchronous Train now; label remaining scenarios phase 2. Separate Nemotron-vs-Qwen results cannot isolate training-method effects.
5. **High — hidden-set gate leaks through selection.** Repeated promotion decisions and public per-question results turn the hidden set into validation data; wording similarity does not prevent family leakage through source procedures or generated cases. Freeze separate train/development/final-test families before generation; gate on development, evaluate the sealed final test once, and publish paired counts and uncertainty.
6. **High — import feasibility is architectural, not an exact-artifact proof.** [Qwen2.5 is supported in both proposed regions](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html), with full Hugging Face weight/config/tokenizer files and documented Transformers 4.51.3 compatibility. Export merged full safetensors, not adapter-only files or an untouched SageMaker tarball; preserve the chat template. [Qwen2.5 lacks Converse support](https://docs.aws.amazon.com/bedrock/latest/userguide/invoke-imported-model.html): verify InvokeModel payloads and identical prompts against both actual imports.
7. **High — workflow completion semantics are missing.** [SageMaker createTrainingJob.sync exists](https://docs.aws.amazon.com/step-functions/latest/dg/connect-sagemaker.html); optimized [Bedrock integration exposes customization, not import .sync](https://docs.aws.amazon.com/step-functions/latest/dg/connect-bedrock.html). Use SDK createModelImportJob→Wait→getModelImportJob with terminal branches, bounded retries and cleanup. Use Standard workflows; split data generation/evaluation into bounded tasks because ordinary [Lambda execution is limited to 15 minutes](https://docs.aws.amazon.com/lambda/latest/dg/gettingstarted-limits.html). Keep torch/TRL in the training container; zip contents including layers are capped at 250 MB.
8. **High — extraction contract and retirement detection need proof.** Current [Box reference permits 1–25 files](https://developer.box.com/reference/post-ai-extract-structured), so one file is a sensible provenance choice, not the documented maximum. [table fields return arrays under answer.field](https://developer.box.com/guides/box-ai/ai-tutorials/extract-metadata-structured), including rows from prose. Prove a facts/procedures schema on the actual account; use stable subject/attribute IDs, retain raw responses and source versions, and never interpret an omitted extraction row alone as a confirmed deletion.
9. **High — Box credentials do not prove access.** [CCG tokens represent a specific service/user subject](https://developer.box.com/guides/authentication/client-credentials); app authorization, folder collaboration, Manage Webhooks scope and AI permissions must all work for that subject. [API access now extends to Business and above with applicable AI Units](https://support.box.com/hc/en-us/articles/45612941554835-Expanded-AI-API-Access-and-AI-Units-for-Business-Business-Plus-and-Enterprise-Plans); Enterprise Plus is not universally required. Add a preflight that lists, downloads, extracts, uploads and registers a webhook using the deployed identity.
10. **High — evaluation job shape is wrong for three modes.** Bring-your-own model-as-judge evaluations are supported, but [each job accepts one response per prompt and one unique modelIdentifier](https://docs.aws.amazon.com/bedrock/latest/userguide/model-evaluation-prompt-datasets-judge.html). Submit one job per mode with matching precomputed source label; keep managed evaluation reporting asynchronous rather than blocking live demo promotion.
11. **High — concurrent sync/training can publish stale knowledge.** Conditional writes alone do not define an immutable approved-data snapshot or prevent an older training run promoting after a newer one. Hash the approved snapshot, record source versions and trigger watermark, allow one training run initially, and compare-and-swap promotion against the expected current version. Only mark a document synced after durable extraction/review storage succeeds.
12. **High — retraining without a fact is not verified unlearning.** Training from the pristine base on the full active set is sensible, but deleting Atlas from examples does not guarantee abstention; a rejected update also leaves the old deployed answer live. Add versioned update/deletion probes and an explicit stale-serving state; block affected answers or visibly label the stale version until a replacement passes. Define bootstrap, ties, minimum gain and safety thresholds.
13. **High — cookie login needs a concrete deployment contract.** Route /api/* through the same CloudFront host with [caching disabled and a compatible origin request policy](https://docs.aws.amazon.com/solutions/improved-single-page-application-performance-using-amazon-cloudfront/); forward cookies, never cache login/API responses, set Secure/HttpOnly/SameSite, and check request origins on mutations. Exempt login as well as the signed webhook; add rate limits and independent session-signing material. Decide whether public static shell routes satisfy the “every route” requirement.
14. **High — sync can lose events or create a feedback loop.** [Box requires 2xx within 30 seconds](https://developer.box.com/guides/webhooks/v2); verify [raw body plus delivery timestamp, freshness and either key](https://developer.box.com/guides/webhooks/v2/signatures-v2), then durably enqueue before acknowledging. Dedupe by body ID. Exclude reports/ from sync, extraction and training; scan all pages, serialize reconciliation, and never infer deletion from a partial/failed listing. Every-minute polling plus extraction cannot guarantee arrival within 60 seconds.
15. **Medium — comparison and expected outcomes are oversold.** BM25 may retrieve both passages in this tiny corpus; fixing its output to fail is an unfair baseline. Freeze chunking/top-k, show retrieved spans, and report actual failures and successes. A few hundred synthetic examples may teach recall without composition; use deterministic value/condition checks plus blinded judge calibration. Teach both systems both knowledge forms, compare each with its own unchanged base, and describe cross-model differences as exploratory.
16. **Medium — costs and destroy are incomplete.** [Qwen inference is billed per CMU per active copy in five-minute windows, with storage charges](https://aws.amazon.com/bedrock/pricing/); read CMUs after import rather than assume token billing. Budget notifications can [arrive after overspend](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html). Cap training/retries/concurrency, tag every runtime-created import, and implement an idempotent cleanup ledger for success, rejection, timeout and partial deployment. [Mac hosts cannot be released before 24 hours](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-mac-instances.html); phase 2 cannot promise immediate complete destroy.

Cuts and simplifications:

- Defer all TensorFold/Mac work, automatic ten-item triggers, general document formats beyond seeded MD/TXT, and the separate Evals screen.
- Start with manual approval and Sync now; add one webhook path once the end-to-end slice works. Treat the minute schedule as recovery.
- Use one tested AWS region, one training configuration, immutable artifacts, a pre-trained fallback version and compact Sources/Review/Learning/Ask screens.
- Build the smallest deployed vertical slice first: Box identity/extract→approved snapshot→SageMaker merge→paired Bedrock invocation→development evaluation. The current foundation/pipeline dependency is circular; separate interface definition from integration, and start the UI against those interfaces early.

Missing pieces:

- Versioned identity for items and procedure families; held-out source exclusion before paraphrase generation; provenance/licensing for the promised general replay examples despite the public-dataset cut.
- Failure/timeout/cancellation states, durable retry delivery, first-version gate semantics, stale-answer behavior, rollback retention policy and cleanup verification after partial failure.
- Separate runtime IAM roles including evaluation S3/model access and scoped PassRole; secret population/rotation steps outside Terraform state; authenticated report access.
- Rehearsal with recorded timings, actual base answers, cached versioned reports and an honest “learning did not improve this case” outcome.

Facts you could not verify:

- Actual AWS/Box account entitlements, quotas, regional capacity, exact model import acceptance, import/first-answer latency and end-to-end training cost; this review performed no deployment.
- A 20-example single epoch reliably changes a fact, or approximately 500 examples reliably improve unseen-family procedures, composition and deletion without regressions.
- TensorFold restart/update/delete behavior on the proposed EC2 Mac configuration, its regional host availability and the quoted $12.50/hour price.
