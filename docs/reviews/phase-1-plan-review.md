**4. AWS/Box correctness**

- **32K and cold start:** retain the proven 32768 configuration, tokenizer/template hashes and full merged safetensors for every import. POC 1 measured roughly 144–169 seconds through scheduled retries; it did not prove a universal startup SLA or that context alone caused the 262K failure. API handlers must return job IDs immediately: HTTP APIs have a hard [30-second integration limit](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-quotas.html).
- **Import workflow:** Standard + SageMaker .sync + start/wait/GetModelImportJob is the correct shape. Bedrock's [optimized integration](https://docs.aws.amazon.com/step-functions/latest/dg/connect-bedrock.html) does not offer import .sync. Add bounded generation/evaluation batches, terminal error handling, idempotent submission, lock expiry/recovery and live slot census. Never delete an arbitrary “oldest non-current” model: retained POC fallback imports have separate ownership. Before the first new train, reconcile existing imports against the three-slot budget.
- **Packaging:** FastAPI/Mangum/box-sdk-gen/boto3 size is unmeasured; the tiny POC echo ZIP proves nothing here. Build a Linux Python 3.12 artifact in wave 2, measure unpacked size and cold-import it. ZIP plus layers is limited to [250 MB; containers allow 10 GB](https://repost.aws/knowledge-center/lambda-deployment-package-size). Keep torch/transformers/PEFT in the SageMaker container.
- **CloudFront:** foundation disables execute-api but supplies no custom domain. [Disabling that endpoint requires access through a custom domain](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-disable-default-endpoint.html); CloudFront pointing to the disabled endpoint will fail. For speed, retain the endpoint with application auth and a checked origin header, or explicitly provision the regional custom domain/certificate. Use CachingDisabled and [AllViewerExceptHostHeader](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/using-managed-origin-request-policies.html), forwarding cookies/query strings, origin/CSRF and signature headers. Set Secure/HttpOnly/SameSite, independent signing material, and test login then protected requests.
- **Box:** POC receiver `poc/box/echo.py` explicitly records `pending_keys`. Require real signatures before accepting events: HMAC-SHA256 over raw body then timestamp bytes, Base64, either matching key, constant-time comparison and freshness. [Box signature contract](https://developer.box.com/guides/webhooks/v2/signatures-v2/). CCG remains unauthorized; [CCG setup](https://developer.box.com/guides/authentication/client-credentials/client-credentials-setup/) requires authorization and appropriate subject access. OAuth is a separate app/consent path, not a mode switch on the CCG app; serialize refresh across Lambdas because [refresh tokens are single-use](https://developer.box.com/guides/authentication/tokens/refresh/). Test list/download/extract/upload/webhook under the deployed actor.
- **Region/claims:** keep Regional resources in us-east-2. The approved Kimi US profile is an explicit cross-Region inference exception, so “all processing in us-east-2” is inaccurate. “No Claude dependency” also overstates the plan: POC Box extraction pins `aws__claude_4_5_haiku`; only direct Bedrock Claude dependence was removed. Keep that qualification.
