Codex (gpt-5.6-sol, xhigh) architecture review, 2026-10-16

Verdict: rethink.

Top risks:
1. **Blocker — 1–2 day scope:** Phase 1 alone includes IAM/Terraform, Box integration, extraction, training, model import, evaluation, six-screen UI, and cleanup; Phase 2 adds scarce Mac hardware and experimental software. This is weeks of integration risk. Fix: ship a narrow, pre-rehearsed Phase 1 demo and defer TensorFold.
2. **Blocker — scenario 5 is not learnable:** E57/X400 and its low-voltage rule appear nowhere in training, so a model cannot infer the fictional correct action. Fix: include the rule in training while holding out wording/situations, or provide the rule in-context and test policy application.
3. **Blocker — live update timing:** Box edit → review → LoRA training → merge → import → evaluation cannot credibly finish in 2–3 minutes. Custom imports alone take several minutes. Fix: demonstrate live sync/review, then switch to a pre-trained v2 model and disclose that shortcut. [AWS import lifecycle](https://docs.aws.amazon.com/bedrock/latest/userguide/invoke-imported-model.html)
4. **High — Bedrock import assumptions:** Qwen2.5 is supported in us-east-1/us-east-2/us-west-2/eu-central-1, but LoRA adapters must be merged into full Safetensors weights. Imported Qwen2.5 does not support Converse, requiring the exact chat template through InvokeModel. Fix: make a 20-example import spike the go/no-go gate. [Supported imports](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html) · [LoRA merging](https://aws.amazon.com/blogs/machine-learning/amazon-bedrock-custom-model-import-now-generally-available/)
5. **High — import capacity and cost:** The default imported-model quota is three, exactly consumed by base + incumbent + candidate. Invocations create billed active copies in five-minute windows, idle models scale to zero, and cold starts can take tens of seconds. Fix: retain only those three, delete rejected/old imports immediately, request quota early, and measure CMUs. [Quotas](https://docs.aws.amazon.com/general/latest/gr/bedrock.html) · [Pricing](https://aws.amazon.com/bedrock/pricing/)
6. **High — Step Functions claim:** SageMaker training supports `.sync`; Bedrock Custom Model Import has no optimized `.sync` integration. Fix: Standard Workflow using `CreateModelImportJob`, Wait, `GetModelImportJob`, Choice, timeout, and cleanup states. [SageMaker integration](https://docs.aws.amazon.com/step-functions/latest/dg/connect-sagemaker.html) · [Bedrock integration](https://docs.aws.amazon.com/step-functions/latest/dg/connect-bedrock.html)
7. **High — SageMaker Spot:** New accounts commonly have zero G5 quota; Spot may queue indefinitely or be interrupted. Container compatibility among CUDA, PEFT, TRL, bitsandbytes, and Transformers 4.51.3 is another dependency. Fix: preflight quota, use on-demand `ml.g5.2xlarge`, pin a tested image, checkpoint, and mirror Qwen weights to S3. [Quotas](https://docs.aws.amazon.com/general/latest/gr/sagemaker.html) · [Managed Spot](https://docs.aws.amazon.com/sagemaker/latest/dg/model-managed-spot-training.html)
8. **High — synchronous APIs:** Lambda permits 15 minutes, but HTTP API integrations time out at 30 seconds; two cold imported models plus search cannot safely complete in one Ask request. Zip packages are limited to 50 MB uploaded/250 MB expanded. Fix: separate per-mode calls or return a job ID and poll; keep ML dependencies out of Lambda or use images. [API limits](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-quotas.html) · [Lambda limits](https://docs.aws.amazon.com/lambda/latest/dg/gettingstarted-limits.html)
9. **High — Box AI contract:** Current guidance says one file per extraction request, while the API reference still permits 1–25 items. Structured extraction supports `table` fields for list output. Box AI APIs are Business+ but may require purchased AI Units and admin enablement—not necessarily Enterprise Plus. Fix: fan out one file per call, use a table schema, and test the actual tenant first. [Guide](https://developer.box.com/guides/box-ai/ai-tutorials/extract-metadata-structured) · [Plans](https://support.box.com/hc/en-us/articles/43797379758739-Box-AI-Features-in-Business-Plans)
10. **High — hidden-test leakage:** Allowing the training-data builder to read hidden questions for similarity checking compromises the holdout; synthetic paraphrases can also leak templates. Fix: freeze and hash the hidden set first, isolate it under separate S3/IAM access, and split by entity/template/procedure family.
11. **High — evidence claim:** Roughly 500 synthetic examples over 20 facts may demonstrate memorization, but a 3B LoRA is not guaranteed to gain two-hop reasoning or procedure generalization. Fix: call this exploratory, pre-register slice-level thresholds, run repeated seeds if possible, and report raw counts rather than a single score.
12. **High — comparison and gate:** “Same model” is fair only with identical checkpoint hash, chat template, decoding parameters, context, and serving path; search is a different RAG baseline. “Beat current without side effects” lacks thresholds and tie rules. Fix: compare within-model deltas, separate cold/warm latency, and define hard per-slice safety gates against the latest truth.
13. **Medium — Bedrock Evaluations:** Bring-your-own responses accepts one response/model identifier per prompt per job, so without/with/search require separate jobs. Fix: keep deterministic checks plus Claude judging in the promotion path; run Bedrock Evaluations asynchronously as post-demo evidence. [Dataset format](https://docs.aws.amazon.com/bedrock/latest/userguide/model-evaluation-prompt-datasets-judge.html)
14. **High — auth and routing:** Login itself must be unauthenticated, contradicting “every route except webhook.” Same-origin cookies work only with explicit CloudFront path, cache, and cookie-forwarding policies. Fix: make `/api/login` public, `/api/box-webhook` signature-only, protect all other API routes, disable caching and the API Gateway default endpoint, and add CSRF/origin checks and throttling. [CloudFront cookies](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/Cookies.html)
15. **High — webhook correctness:** Box requires a 2xx within 30 seconds and retries failures; signature verification uses raw body plus timestamp. The body event ID—not the delivery header—is stable across retries. Fix: verify primary/secondary HMAC with a timing-safe comparison, dedupe on body ID, enqueue asynchronously, and retain scheduled reconciliation. [Box webhooks](https://developer.box.com/guides/webhooks/v2/) · [Signatures](https://developer.box.com/guides/webhooks/v2/signatures-v2/)
16. **High — cleanup and budgets:** Imported models are not managed by CloudFormation, and Budgets is delayed rather than a hard cap. Terraform cannot alone guarantee import/webhook cleanup; manual state-bucket removal also contradicts one-command destroy. Fix: maintain an ownership ledger, tag every resource, cap concurrency/runtime, and implement exact-target imperative cleanup. [Import limitation](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html) · [Budget latency](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html)
17. **Blocker — Phase 2 infrastructure:** EC2 Mac requires a Dedicated Host, has a 24-hour minimum allocation, On-Demand billing, default quota zero, and limited capacity. A private subnet also needs SSM endpoints and outbound access for installation/model download. Fix: defer Phase 2; if retained, reserve quota/capacity and budget before coding. [EC2 Mac](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-mac-instances.html) · [Mac quotas](https://docs.aws.amazon.com/ec2/latest/instancetypes/ec2-instance-quotas.html)

Cuts and simplifications:
- Ship Phase 1 only; remove every TensorFold/EC2 Mac task from the hackathon critical path.
- Use one region, on-demand G5, manual Train now, one document format, 8–12 facts, and 3–4 procedures.
- Demo live Box edit → webhook → extraction → review; use pre-trained/imported v1 and v2 for model switching.
- Keep Sources, Review, Ask, and one combined results page; cut separate Learning, Hidden, and Evals screens.
- Keep deterministic evaluation plus one Claude judge; make Bedrock Evaluations a stretch goal.
- Replace automatic “10 approved” training with a concurrency-locked manual workflow.
- Do not claim weight-generated source labels are citations; call them training lineage. Only retrieval spans are verifiable citations.
- Resolve the Phase 1 runbook contradiction: scenarios 1, 2, 3, and 6 currently depend on Phase 2.

Missing pieces:
- A fail-fast account preflight for quotas, model access, imported-model count, Box authorization/scopes, AI Units, and projected spend.
- Atomic promotion/rollback pointers, execution idempotency, concurrency locks, timeouts, and stale-version handling.
- Frozen hidden-set manifest/hash and IAM isolation from generators and training jobs.
- Exact Qwen artifact hash, license/provenance, chat template, inference payload, and S3 model mirror.
- CCG service-account collaboration with the Halvard folder and required file, webhook, and `ai.readwrite` scopes.
- Safe cleanup manifest covering Box webhook, imported models, S3 objects, ECR images, logs, and delayed Mac-host release.
- For Phase 2: EBS sizing, NAT/endpoints, bootstrap/systemd, private bind address, security group, API key, and host-release workflow.

Facts you could not verify:
- Tyson’s applied SageMaker GPU/Spot, Bedrock import, and EC2 Mac quotas or current regional capacity.
- Exact 500-example training, merge, import, evaluation, cold-start timings, CMUs, and total cost.
- The Box tenant’s plan, AI-unit balance, enabled models, administrator approval, and actual one-versus-many-file behavior.
- Whether the proposed LoRA produces measurable recall, composition, procedure, or safety gains.
- Current `mac-m3ultra.metal` regional price/capacity and TensorFold behavior on that exact host; local documentation only supports roughly 1.5–3 minutes per fact on its tested setup.
